# Design

## Context

当前原记录旁路包只引用[原R07续接绑定](../../../evidence/R07/report-concurrency.md#2026-10-28-原记录旁路续接绑定)，沿原B08-06/B09的历史保留契约、原生权限和生命周期；不改Frappe、不新增产品API/角色权限；HTTP另建独立测试角色和用户，不改旧共享岗位。单价/效率旧包已限定收口，不重开。当前5个新增受控方法已分批通过，限定HTTP及专用站最终保留已核；公开保存仍待核，本包未收口；现场、G1/G2/G3、Z01保持原门槛。

动机和范围见[proposal.md](proposal.md)。当前做/不做/通过条件及有限验收由[原卡原记录旁路子节](../../../docs/任务卡/02-生产与物料闭环.md#2026-10-28-原记录旁路续接)及其R07链接规定；上一包范围保留为历史，不复制方案正文。

## Goals / Non-Goals

**Goals:** 保持原卡为唯一验收与进度来源，用 OpenSpec 聚合其入口和本批证据。

**Non-Goals:** 不新建权限/计算框架、平行清单或独立工作树；不把工具规划状态当业务通过。

## Decisions

- 复用`.development/repos/erpnext`的`codex/xgd-maintenance`工作副本，保留累计25份改动源码；本轮原控制器及原测试2份变化后，测试/Web/构建镜像三处33份指定文件已按本包清单核对，源测试站11表保持。新工作树不会自动带入累计补丁，故继续既有维护checkout，不用旧核对冒充本包验证。
- 原fixture与runner模式继续复用，`TestProductionReportHistoryPaths`/`b08_history_paths_tests.py`的真实方法、分批结果及两处失败见[本包记录](../../../evidence/B08/history-paths-20261028/run-record.md)。仅原工序控制器按持久化name查已提交/已取消Job Card引用，保护直存、提交后更新和删除；仅取消态fixture由受控服务器上下文调用原生cancel构造，不开放客户端取消。Resource/client/同步批量各自留证，合法请求被历史保护拒绝才算命中，独立回读原关联/事实；批量逐条commit不包装成事务内整批原子回滚。无事实草稿正例保留，既有计价保护不能替代历史关联验证。实际7个不同拒绝写入及6个合法草稿操作未重放，6次业务保护与1次原生取消态417分别留证；已删子行GET403经授权父读取和独立DB核删除，3批脚本停止和1次本地语法错误保留，不算产品失败。结果及专用站旧11业务表/5安全表保留沿原R07引用，不重复清单。
- 使用默认 `spec-driven` 与 `skip_specs: true`：本次没有新增或改写需求，故引用已有契约；`tasks.md` 也只引用原卡。接受 CLI 不解析外部复选框的限制，不另建自定义 schema 或重复任务以凑齐状态。

## Risks / Trade-offs

- [CLI 规划文件状态可能被误读为实现完成] → 原卡和本批实际证据权威；不归档未完成包，不用 CLI 状态增加完成数。
- [历史样例已消耗、旧证据有限] → 不重放旧 HTTP 批，不把受控测试/页面/现场或完整 G1/G2/G3 混为一谈；按原卡保留停止和交付边界。
